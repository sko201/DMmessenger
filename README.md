# Микро-мессенджер — клиент (ПК)

Electron-клиент для внутреннего мессенджера. Серверная часть не публикуется —
доступ к серверу только по инвайт-коду от администратора.

## Установка

Понадобится Node.js 18+.

```bash
git clone <адрес этого репозитория>
cd <папка репозитория>
npm install
npm start
```

## Первый запуск

1. Вкладка **Регистрация** → адрес сервера (спроси у админа), свой ник
   (ровно как в выданном тебе инвайте), пароль (от 6 символов), код
   приглашения.
2. После успешной регистрации — вкладка **Вход**, логинишься тем же ником
   и паролем.
3. Дальше клиент сам запоминает сессию — при следующем запуске логиниться
   заново не нужно (кнопка "выйти" сбрасывает сессию вручную).

Если сервер сейчас выключен — увидишь "нет соединения, переподключение...";
клиент сам переподключится, как только сервер снова будет доступен.

## Протокол (для тех, кто хочет написать свой клиент)

Серверу всё равно, какая программа к нему стучится — официальный клиент,
самописный, или просто curl. Главное — соблюдать формат запросов.

### REST — разовые действия

**`POST /api/register`**
```json
{ "username": "ник", "password": "пароль", "inviteCode": "код" }
```
Код одноразовый и привязан к конкретному нику — сработает только если
`username` совпадает с тем, для кого код выпущен.

**`POST /api/login`**
```json
{ "username": "ник", "password": "пароль" }
```
Ответ: `{ "ok": true, "token": "...", "username": "..." }`. Токен живёт,
пока сервер не перезапущен (сессии не персистентны между рестартами
сервера).

**`GET /api/contacts`**
Ответ: `{ "users": ["ник1", "ник2", ...] }` — список всех
зарегистрированных пользователей, для составления списка личек.

### WebSocket — всё в реальном времени

Подключение: `ws://адрес-сервера/ws?token=ТВОЙ_ТОКЕН`

**Отправить сообщение** (клиент → сервер):
```json
{ "type": "send", "chat": "lobby", "text": "привет всем" }
```
Для личного сообщения `chat` — это ник собеседника вместо `"lobby"`.

**Запросить историю чата** (клиент → сервер):
```json
{ "type": "history", "chat": "lobby" }
```

**Входящее сообщение** (сервер → клиент):
```json
{ "type": "message", "chat": "lobby", "message": { "id", "from", "to", "text", "ts" } }
```

**История в ответ на запрос** (сервер → клиент):
```json
{ "type": "history", "chat": "lobby", "messages": [ /* ... */ ] }
```

**Кто сейчас онлайн** (сервер → клиент, шлётся автоматически при
подключении/отключении любого участника):
```json
{ "type": "presence", "online": ["ник1", "ник2"] }
```

Этого достаточно, чтобы написать полностью свой клиент — сервер не
проверяет ничего, кроме валидности токена и формата сообщений.
